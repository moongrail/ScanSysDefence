# ScanSysDefence — анализ безопасности Windows

> ⚠️ **DRAFT / ALPHA.** Это ранняя альфа-версия: интерфейс и поведение могут меняться,
> функции проверялись только в тестовой виртуальной машине (VirtualBox, Windows 10 LTSC).
> Не используйте на рабочих системах без резервных копий.

**ScanSysDefence** — настольная утилита для Windows 10/11, которая находит слабые места системы,
объясняет риски по-русски и помогает безопасно их устранить: с карантином, `.reg`-бэкапами
и журналом действий.

## Возможности

- **Сканирование** — службы, драйверы, автозапуск, процессы, задачи планировщика,
  WMI-подписки, расширения браузеров.
- **Оценка риска** — подписи, пути запуска, права, телеметрия: понятные русские описания
  и рекомендации.
- **Действия** — остановить/отключить службу, завершить процесс, отключить задачу или
  автозапуск: с подтверждением, проверкой результата и журналом.
- **Карантин** — зашифрованное хранение, восстановление на прежнее место, удаление.
- **Починка реестра** — реальные исправления с `.reg`-бэкапом и сменой владельца
  защищённых ключей.
- **Очистка дисков** — выбор диска, категории мусора, безопасное удаление.
- **Проверка диска** — поиск вирусов/шпионов/троянов: EICAR, двойные расширения,
  маскировка PE, опасные скрипты, строки майнеров, `autorun.inf`, подозрительные имена.

## Технологии

- .NET 8 / WPF / C#, MVVM
- MaterialDesignInXamlToolkit
- WMI (`System.Management`), Task Scheduler COM API, Win32 P/Invoke
- xUnit — 49 тестов
